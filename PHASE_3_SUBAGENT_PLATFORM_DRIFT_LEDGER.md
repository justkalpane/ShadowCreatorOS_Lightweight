## Classification summary
- Strongest content-script drift: `cwf_210`, `cwf_220`, `cwf_230`, `cwf_240`, `wf_200`

- Best reusable governance/support lanes: `wf_000`, `wf_001`, `wf_010`, `wf_020`, `wf_021`, `wf_022`, `wf_023`, `wf_900`, `wf_340`
- Best refactor candidates for film mode: `cwf_110`, `cwf_120`, `cwf_130`, `cwf_140`, `cwf_310`, `cwf_430`

## Interpretation
The subagent layer is not broken. It is mostly well-structured support infrastructure with one clearly content-script-biased family and a set of downstream media/publishing/analytics lanes that should remain downstream. The core conversion work is to duplicate or refactor the script family into film-first equivalents without erasing the current content route.
