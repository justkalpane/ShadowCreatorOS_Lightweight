# Copyright Safe Film Intelligence Contract

Phase: PHASE_13D_F7

This contract allows the cinema engine to use filmmaking principles, labels,
structural concepts, and original deterministic packet fields without copying
protected book text, paid-course material, proprietary templates, or verbatim
screenplay examples.

Allowed:

- high-level storytelling principles
- original deterministic schemas and validators
- user-provided payload facts
- public-domain mythology role logic
- repo-local contracts and generated packet structures

Forbidden:

- verbatim paid course text
- copyrighted beat sheet prose copied from books
- proprietary template replication
- claiming external source-backed truth without a source ledger
- using GitHub or repo reads as governed runtime proof

Boundary:

`SCRIPT_GENERATION` remains the content route. `FILM_SCREENPLAY_GENERATION`
may use cinema craft principles only for script-only preproduction packets.
`MEDIA_FACTORY_HANDOFF` remains downstream and is not triggered by this layer.
