# Gold Result Reference Pack

## Purpose

This file is a consolidated reference pack for best-result patterns only.
It is not the routing brain, not the validator brain, and not the source of
truth for execution law.

Use this file when a route needs one lightweight place to remember what a
strong result looks like without loading multiple long example files.

## Reference Status

- Gumloop benchmark output is reference only.
- Antigravity finalized script behavior is reference only.
- Antigravity finalized visual media plan behavior is reference only.
- Antigravity visual media generator expectations are reference only.

Routing, contracts, validators, and approved route manifests remain the source
of truth.

## Layer Separation Law

These three layers must not be collapsed into one another:

1. `SCRIPT_GENERATION`
2. `VISUAL_MEDIA_PLAN`
3. `VISUAL_MEDIA_GENERATOR_DRAFT`

If a route mixes these layers, it is shallow even when the output looks long.

## Gold Reference Expectations

### Script Generation

- Strong opening hook variants.
- One selected opening hook with justification.
- Real recurring re-hooks, not one opening hook only.
- Cinematic short story block before teaching.
- Spoken script body is sized for the declared duration, not a short-form
  motivational answer wearing a 5-minute label.
- Dynamic beat map tied to retention and editing.
- Fact-vs-anecdote handling for real-person proof.

### Visual Media Plan

- Scene-by-scene storyboard logic stays readable.
- Each scene is broken out in its own vertical table or equivalent scene block.
- Visual method is clearly assigned per scene.
- Voice, music, SFX, captions, editing, color, and safe-zone logic are all
  visible scene by scene.
- Cost distribution and B-roll percentage are explicit.

### Visual Media Generator Draft

- Generator draft is not a storyboard-only plan.
- Exact generation order is locked.
- Exact save-path order is locked.
- Exact assembly order in DaVinci is locked.
- Mission folder structure is defined before execution.
- Support files for image, voice, music/SFX, editing, HyperFrames, and packet
  JSON are explicitly listed.
- Asset handoff targets are clear enough for Codex, Antigravity, Claude, or
  operators to execute without improvising structure.

## Readability Preservation

The preferred scene presentation style is:

- one scene heading at a time
- one vertical scene table at a time
- no giant side-by-side merged storyboard table as the only readable form

Matrix summaries may still exist, but they do not replace per-scene readable
breakout blocks.

## Mission Folder Expectation

When production mode is approved, the mission should use one dedicated mission
folder with:

- one consolidated human-readable master plan document
- packet JSON files
- support TXT files for image, voice, music/SFX, editing, and HyperFrames
- separated output folders for A-roll, B-roll, images, music, SFX, voice,
  HyperFrames, DaVinci, and proofs

Temporary generation scratch files may exist during execution, but they should
be deleted or archived when the task is completed successfully.

## Anti-Drift Reminder

Reference artifacts teach the shape of a strong result.
Contracts define what must exist.
Validators decide whether the result passes.
